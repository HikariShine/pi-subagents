### 关键路径对照

| 路径类型 | 示例值 | 说明 |
|----------|--------|------|
| `cfgPath` | `{TEMP}/async-cfg-{id}.json` | 配置文件，runner读取 |
| `asyncDir` | `{TEMP}/async-subagent-runs/{id}/` | 异步运行目录 |
| `resultPath` | `{TEMP}/async-subagent-results/{id}.json` | **硬编码结果路径** |
| `sessionDir` | `{asyncDir}/async-{id}/` | 子代理Session目录 |
| `artifactsDir` | `配置指定` | 产物目录（可配置） |

### 执行流程

```
spawnRunner
    ↓
fs.writeFileSync(cfgPath, JSON.stringify(cfg))
    ↓
spawn(process.execPath, [jitiCliPath, runner, cfgPath], {
    detached: true,
    stdio: "ignore"
})
    ↓
subagent-runner.ts 读取 cfgPath
    ↓
内部调用 pi run 执行子代理
    ↓
结果写入 resultPath
```

### 设计要点

1. **配置化启动**：所有参数写入 JSON 文件，避免命令行过长
2. **硬编码结果路径**：`RESULTS_DIR` 固定在临时目录，不可配置
3. **分离进程**：`detached: true` + `stdio: "ignore"` 完全独立运行
4. **Intercom 通信**：通过 `controlIntercomTarget` 和 `childIntercomTargets` 建立双向通道

### subagent-runner.ts 执行命令

实际执行命令：
```bash
node 'E:\Project\AiLearn\pi-mono\node_modules\jiti\lib\jiti-cli.mjs' \
  E:\Project\AiLearn\pi-mono\packages\pi-subagents\subagent-runner.ts \
  'C:\Users\guang\AppData\Local\Temp\pi-subagents-user-guang\async-cfg-{id}.json'
```

**关键点**：
- 不是直接 `pi run`，而是通过 `jiti` 执行 `subagent-runner.ts`
- `jiti` 是 TypeScript 运行时，无需编译直接执行 `.ts` 文件
- `subagent-runner.ts` 读取 JSON 配置，内部再调用 `pi run`
