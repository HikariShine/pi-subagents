### createForegroundControlNotifier 详解

**作用**: 创建控制事件通知器的工厂函数

**核心逻辑**:
```typescript
function createForegroundControlNotifier(data, deps): (event: ControlEvent) => void {
    return (event) => emitControlNotification({ pi, controlConfig, intercomBridge, event });
}
```

**emitControlNotification 双通道通知**:
1. **Event Bus** (`SUBAGENT_CONTROL_EVENT`) - 本地通知，index.ts 接收
2. **Intercom** (`SUBAGENT_CONTROL_INTERCOM_EVENT`) - 远程通知，跨进程通信

**通知渠道对比**:
| 渠道 | 范围 | 目标 | 用途 |
|------|------|------|------|
| event | 同进程 | controlEventHandler | 本地 UI 通知 |
| intercom | 跨进程 | orchestratorTarget | 远程控制协调 |

**ControlEvent 类型**: paused | resumed | interrupted | error | completed

### 关键理解

- `runSync` 是真正启动子进程的底层执行器
- `cleanTask` 保存原始任务用于记录，`task` 注入输出指令后用于执行
- `foregroundControl` 实时更新：执行前注册中断，执行中更新活动状态，执行后清理
- 6种返回结果：detached（Intercom分离）、interrupted（暂停）、failed（失败）、success（成功）
- `runSync` vs `executeAsyncSingle`：前者阻塞等待，后者立即返回后台执行
